How I work

Design first

I start with the idea and the audience. Layout and type and motion follow from there.

Code and AI, honestly

I know the basics of HTML, CSS and JavaScript and I understand what the code does. For larger builds I use AI tools and direct them with clear briefs. I check the results and correct them myself.

I deliver

The sites go live and work for the client. I plan my time well and I keep to deadlines.
